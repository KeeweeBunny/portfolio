# Portfolio – Documentation du projet

## Présentation du projet

Dans le cadre de ma formation au développement web à Epitech - Lille, j’ai réalisé un portfolio statique afin de présenter mon profil, mes compétences et mes projets.

Ce portfolio a été réalisé à l’aide du générateur de site statique **Jekyll**, puis déployé en ligne via **GitHub Pages**.

---

## Objectifs

Les objectifs de ce projet étaient :

* Créer un site web personnel
* Présenter succinctement mes projets & compétences
* Apprendre à utiliser Jekyll
* Utiliser Git et GitHub
* Déployer un site en ligne via Github Pages

---

## Technologies utilisées

* BASH
* HTML
* CSS
* Markdown
* Jekyll
* Git
* GitHub Pages

---

## Organisation du projet

Le site est structuré en plusieurs pages :

* Accueil
* About
* Projects
* Contact

J’ai utilisé un template et ses layouts Jekyll afin de séparer le contenu et la structure du site.

---

## Difficultés rencontrées

Durant ce projet, j’ai rencontré plusieurs difficultés :

* Gérer les permalinks et la navigation entre les pages lors de modification du template
* Déployer correctement le site avec GitHub Pages en le pushant sur deux repo différents (perso & école)
* Découper le projet pour mieux m'y prendre & organiser l’arborescence du projet

Ces difficultés m’ont permis de mieux comprendre le fonctionnement de Jekyll, la gestion de la navigation entre les pages, l’organisation d’un projet web et le déploiement d’un site en ligne avec GitHub Pages.

---

## Compétences acquises

Grâce à ce projet, j’ai appris à :

* Utiliser Jekyll
* Structurer un projet web
* Utiliser Git et GitHub plus en profondeur
* Déployer correctement un site avec GitHub Pages
* Créer un portfolio professionnel

---

## Conclusion

Ce projet m’a permis de créer mon premier portfolio en ligne et de mettre en pratique certaines de mes compétences en développement web.
Je sais de source sûre qu'il me servira de support pour présenter mon profil et mes projets à des recruteurs.

	# Forty - Jekyll Theme

	A Jekyll version of the "Forty" theme by [HTML5 UP](https://html5up.net/).  

	![Forty Theme](assets/images/forty.jpg "Forty Theme")

	# How to Use

	For those unfamiliar with how Jekyll works, check out [jekyllrb.com](https://jekyllrb.com/) for all the details, 
	or read up on just the basics of [front matter](https://jekyllrb.com/docs/frontmatter/), [writing posts](https://jekyllrb.com/docs/posts/), 
	and [creating pages](https://jekyllrb.com/docs/pages/).

	Simply fork this repository and start editing the `_config.yml` file!

	> NOTE: GitHub Actions is required to deploy to GitHub Pages because GitHub [refuses to update their version of Jekyll](https://github.com/github/pages-gem/issues/651).

	# Added Features

	* **[Formspree.io](https://formspree.io/) contact form integration** - just add your email to the `_config.yml` and it works!
	* Use `_config.yml` to **set whether the homepage tiles should pull pages or posts**, as well as how many to display.
	* Add your **social profiles** easily in `_config.yml`. Only social profiles buttons you enter in `config.yml` show up on the site footer!
	* Set **featured images** in front matter.
